# Maafin Aku Yuk? 💗

Website hadiah digital / permintaan maaf interaktif.

## Fitur
- Permintaan maaf interaktif
- Tombol "NGGAK" jahil
- Confetti dan floating hearts
- Halaman kejutan
- Agenda: Kamis, 8 Oktober 2026 pukul 13:30 WIB
- Countdown real-time menuju 13:30 WIB
- Dark mode
- Easter egg pesan rahasia
- LocalStorage
- Responsive HP & laptop

## Menjalankan di VS Code
1. Ekstrak ZIP.
2. Buka folder di VS Code.
3. Buka `index.html` dengan Live Server, atau klik dua kali `index.html`.
4. Pastikan tanggal/jam komputer benar.

## Hosting gratis
Paling mudah: GitHub Pages.
1. Buat repository baru di GitHub.
2. Upload `index.html`, `style.css`, `script.js`, dan folder `assets`.
3. Masuk Settings > Pages.
4. Pada Build and deployment pilih `Deploy from a branch`.
5. Branch: `main`, folder: `/ (root)`.
6. Save.
7. Tunggu beberapa menit, lalu GitHub memberikan link website.

Alternatif mudah: Netlify Drop atau Cloudflare Pages.
